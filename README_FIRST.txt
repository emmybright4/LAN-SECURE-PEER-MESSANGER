LAN SECURE PEER MESSENGER - USER GUIDE
=====================================

FIRST TIME SETUP
----------------
When Windows Firewall asks, click ALLOW ACCESS

QUICK START
-----------
1. Run on ALL computers
2. Create account or Login
3. Click "Auto-Exchange Keys"
4. Select user and chat

TROUBLESHOOTING
---------------
• No users? Check firewall
• Can't send? Verify user online
• Keys not working? Exchange again
